## What we build

Decuff builds self-hosted, LLM-driven offensive-security tooling. A planner
decomposes a goal into intents, workers execute them with real tools, and every
finding stays bound to the assets and captured traffic that prove it — with
human-in-the-loop approvals, scope and deny gates, and budget controls around
every autonomous action.

- **Breach** — autonomous penetration testing with evidence-backed findings and a
  multi-tenant console at [breach.decuff.ai](https://breach.decuff.ai).

## Responsible use

Our tools are built for **authorized** security testing within explicitly defined
scopes. You are responsible for obtaining written permission before testing any
system you do not own, and for complying with all applicable laws. Decuff does not
condone or support unauthorized access.
